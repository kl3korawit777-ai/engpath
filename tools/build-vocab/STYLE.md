# STYLE.md — กฎกลางสำหรับเขียนข้อมูลคำศัพท์ (ใช้ทุกชุด)

เอกสารนี้คือกฎที่ Claude Code ต้องอ่านก่อนเขียนทุกชุด (`work/batches/batch-NNN.output.json`) และที่ validator ใช้ตรวจ
ถ้ากฎในไฟล์นี้ขัดกับ validator ให้ยึด validator (`src/validate.mjs`) แล้วแก้ไฟล์นี้ให้ตรง

## 1. งานของแต่ละชุด
- input: `work/batches/batch-NNN.input.json` — 100 คำตามลำดับ rank แต่ละคำมีข้อมูลที่ได้จาก Wiktionary แล้ว: `wiktionary.pos`, `ipa`, `senses` (ความหมายอังกฤษ), `thCandidates` (คำแปลไทยจาก Wiktionary แยกตามชนิดคำ/ความหมาย), `exampleRefs` (ประโยคของ Wiktionary — อ่านเพื่อรู้บริบท **ห้ามลอก**), `synonyms`/`antonyms`/`family` (เฉพาะคำที่อยู่ในคลัง), `phrases` (วลีจาก derived terms ใช้เป็นแรงบันดาลใจได้)
- output: `work/batches/batch-NNN.output.json` — อาร์เรย์ของออบเจ็กต์ 100 รายการ (หนึ่งรายการต่อหนึ่งคำ ตามลำดับ rank) **ครบทุกคำของชุด ไม่ขาดไม่เกิน**
- ข้อมูลที่ Wiktionary ให้มาแล้ว (IPA, ความหมายอังกฤษ, คำพ้อง/ตรงข้าม, ตระกูลคำ) สคริปต์ใส่ให้เอง — ในไฟล์ output **เขียนเฉพาะส่วนที่ต้องแต่ง** ตาม schema ข้างล่าง

## 2. Schema ต่อคำ (ไฟล์ output)

```json
{
  "rank": 409,
  "word": "decide",
  "pos": ["verb"],
  "th": [
    { "pos": "verb", "text": "ตัดสินใจ", "source": "wiktionary", "basedOn": "ตัดสินใจ" },
    { "pos": "verb", "text": "ลงความเห็น", "source": "claude" }
  ],
  "examples": [
    "We decided to walk home after the movie.",
    "She cannot decide which shirt to buy."
  ],
  "collocations": ["decide to go", "decide on a name", "hard to decide"],
  "family": ["decision"],
  "tags": ["daily-life"],
  "cefr": "A2"
}
```

| ฟิลด์ | กฎ |
|---|---|
| `rank`, `word` | ต้องตรงกับ input เป๊ะ (ตัวพิมพ์ตามที่ให้มา) |
| `pos` | 1–3 ชนิดคำหลัก เรียงจากที่ใช้บ่อยสุด ค่าที่อนุญาต: noun, verb, adjective, adverb, preposition, conjunction, pronoun, determiner, interjection, number, modal, auxiliary, particle · ต้องมีอย่างน้อย 1 ชนิดที่ตรงกับ `wiktionary.pos` (ถ้า Wiktionary มีคำนี้) · เลือกเฉพาะชนิดที่ผู้เรียนระดับนี้พบบ่อย ไม่ต้องใส่ทุกชนิดที่ Wiktionary มี |
| `th` | 1–3 ความหมาย **เรียงจากใช้บ่อยสุด** แต่ละอัน `{pos, text, source, basedOn?}` — กฎละเอียดข้อ 3 |
| `examples` | **2 ประโยค** แต่งใหม่ทั้งหมด — กฎละเอียดข้อ 4 |
| `collocations` | 2–4 วลีที่ใช้บ่อย (2–5 คำ) ควรมีคำนั้นหรือรูปผัน ไม่ซ้ำกัน ใช้รูปที่ผู้เรียนเอาไปใช้ได้จริง เช่น `make a decision`, `look forward to` |
| `family` | **เพิ่ม**เฉพาะคำตระกูลเดียวกันที่ Wiktionary ไม่ได้ให้มา (ถ้ามี) 0–6 คำ — ต้องเป็นคำที่ **อยู่ใน 5,050 คำของคลัง** เท่านั้น (ไม่งั้น validator ไม่ผ่าน) ตัวพิมพ์เล็ก ไม่ซ้ำ ไม่ใช่ตัวคำเอง · ถ้าไม่แน่ใจว่าอยู่ในคลังหรือไม่ ใส่ `[]` |
| `tags` | 1–3 แท็กจากรายการข้อ 5 เท่านั้น ห้ามสร้างแท็กใหม่ |
| `cefr` | A1 / A2 / B1 / B2 / C1 — ระดับที่ผู้เรียนมักเจอคำนี้ครั้งแรก (ใช้ `cefrHint` ใน input เป็นจุดตั้งต้น ปรับได้ถ้าคำนั้นเด่นชัดว่าง่าย/ยากกว่า) |

## 3. กฎคำแปลไทย (`th`)
**รูปแบบ**
- สั้น กระชับ เป็นภาษาไทยธรรมชาติที่คนใช้จริง ไม่เกิน ~25 ตัวอักษร ไม่มีวงเล็บอธิบายยาว ไม่ใส่ชื่อชนิดคำในข้อความ (pos อยู่ในอีกฟิลด์)
- ไม่ทับศัพท์ถ้ามีคำไทยที่ใช้กันทั่วไป · ถ้าคำนั้นเป็นคำทับศัพท์ในชีวิตจริง (เช่น “ฟรี”, “โทรศัพท์”) ใช้ได้
- เลือกรูปให้เหมาะกับชนิดคำ: กริยา = กริยาไทยตรง ๆ (“ตัดสินใจ”) · นามที่เป็นนามธรรม ใช้ “การ…/ความ…” เมื่อจำเป็นเพื่อแยกจากกริยา (“การตัดสินใจ”, “ความสุข”) · คุณศัพท์ = “…” โดยไม่ต้องมี “ที่”
- คำไวยากรณ์ (the, of, to ฯลฯ): อธิบายหน้าที่สั้น ๆ ได้ เช่น “(ใช้นำหน้านามที่เฉพาะเจาะจง)” → ถ้าไม่มีคำไทยตรง ให้เขียนหน้าที่ย่อ ๆ แต่ไม่เกินความยาวข้างบน
- 1–3 ความหมาย ไม่ซ้ำกัน เรียงจากความหมายที่พบบ่อยที่สุดสำหรับผู้เรียน (ไม่ใช่ลำดับในพจนานุกรม) ความหมายที่หายาก/โบราณ/คำสแลงอย่าใส่

**แหล่งที่มา (`source`) — บังคับทุกความหมาย**
1. **ถ้า `thCandidates` มีตัวเลือกที่ตรงกับความหมายนั้น ให้ใช้ก่อนเสมอ** → `source: "wiktionary"` และต้องมี `basedOn` = ข้อความไทยของตัวเลือกจาก Wiktionary ที่ใช้เป็นฐาน (คัดลอกให้ตรงตัวอักษร) — `text` ปรับถ้อยคำให้เป็นธรรมชาติได้ (ตัดคำซ้ำ เปลี่ยนเป็นรูปที่ใช้จริง) **แต่ห้ามเปลี่ยนความหมาย**
2. **เขียนความหมายใหม่เฉพาะเมื่อ** ไม่มีตัวเลือกเลย หรือตัวเลือกไม่ครอบคลุมความหมายหลักของคำ → `source: "claude"` (ไม่มี `basedOn`) — validator จะเตือนถ้ามีตัวเลือกจาก Wiktionary ของชนิดคำนั้นแต่ไปใช้ claude ให้ทบทวนว่าจำเป็นจริงไหม
3. ความหมายหลัก (`th[0]`) ที่ source เป็น claude จะถูก flag ในรายงานตรวจทานทุกคำ — ใช้ claude เฉพาะที่จำเป็นจริง ๆ
4. ห้ามใช้ `source: "manual"` (สงวนไว้สำหรับ overrides.json ที่ผู้ดูแลแก้เอง)
5. `pos` ของแต่ละความหมายต้องอยู่ใน `pos` ของคำ

## 4. กฎประโยคตัวอย่าง (`examples`) — 2 ประโยค แต่งใหม่ทั้งหมด
- **มีคำนั้นหรือรูปผัน** (decide → decided, deciding, decides; go → went, gone) · ยาว **≥ 4 คำ**
- ความยาวสูงสุดที่แนะนำตามระดับของคำ: ระดับ 1–4 ≤ 12 คำ · ระดับ 5–8 ≤ 16 คำ · ระดับ 9–11 ≤ 20 คำ (เกินแล้ว validator เตือน, เกิน 30 คำไม่ผ่าน)
- ใช้คำศัพท์ง่ายกว่าคำเป้าหมาย (ผู้เรียนต้องเข้าใจประโยคได้โดยไม่ต้องเปิดดูคำอื่น) ไวยากรณ์พื้นฐาน
- **แต่งใหม่ทั้งหมด** — ห้ามคัดลอก/ปรับเล็กน้อยจาก `exampleRefs` ของ Wiktionary (ถ้าตรงกัน validator ไม่ผ่าน) ห้ามยกคำพูดจากหนังสือ เพลง หรือข่าว
- สองประโยคต้องต่างบริบท/ความหมาย (ถ้าคำมีหลายความหมายหลัก ให้ครอบคลุมต่างกัน) และ **ไม่ซ้ำกับประโยคใดในคลังทั้งชุด** (validator ตรวจข้ามชุด) — หลีกเลี่ยงโครงประโยคสำเร็จรูปซ้ำ ๆ เช่น “I like X.” ทุกคำ
- เนื้อหาเป็นกลาง ใช้ได้ในชีวิตประจำวัน/เรียน/ทำงาน ไม่มีชื่อบุคคลจริง แบรนด์ การเมือง ศาสนา เรื่องเพศ ความรุนแรงรุนแรง หรือเนื้อหาที่อาจทำให้ผู้เรียนไม่สบายใจ
- เขียนเป็นประโยคสมบูรณ์ ขึ้นต้นตัวพิมพ์ใหญ่ จบด้วย . ? !
- ชื่อวัน/เดือนและคำเฉพาะ (Monday, January) เขียนตัวพิมพ์ใหญ่ตามปกติ

## 5. แท็กที่อนุญาต (เลือก 1–3 ตามหัวข้อที่คำนี้พบบ่อยที่สุด)
| แท็ก | ใช้กับ |
|---|---|
| `daily-life` | ชีวิตประจำวัน บ้าน อาหาร ของใช้ เวลา วัน/เดือน ตัวเลข คำพื้นฐานทั่วไป |
| `science` | วิทยาศาสตร์ คณิตศาสตร์ การวิจัย ข้อมูล การวัด |
| `health` | สุขภาพ ร่างกาย การแพทย์ กีฬา โภชนาการ |
| `education` | การเรียน โรงเรียน มหาวิทยาลัย ความรู้ ภาษา |
| `work` | การทำงาน ธุรกิจ การเงิน เศรษฐกิจ อาชีพ |
| `travel` | การเดินทาง สถานที่ ที่พัก การท่องเที่ยว ยานพาหนะ |
| `emotion` | อารมณ์ ความรู้สึก ความคิดเห็น บุคลิก ความสัมพันธ์ส่วนตัว |
| `society` | สังคม กฎหมาย การเมือง วัฒนธรรม ชุมชน สื่อ |
| `technology` | เทคโนโลยี คอมพิวเตอร์ อินเทอร์เน็ต เครื่องมือ |
| `nature` | ธรรมชาติ สัตว์ พืช สภาพอากาศ สิ่งแวดล้อม |
- คำไวยากรณ์ที่ใช้ทั่วไปมาก (the, of, to, because) ใช้ `daily-life` เป็นค่าตั้งต้น

## 6. ระดับ CEFR (`cefr`)
ระดับ 1–2 ของคลัง (rank 1–800) ≈ A1–A2 · ระดับ 3–4 ≈ A2–B1 · ระดับ 5–6 ≈ B1 · ระดับ 7–8 ≈ B1–B2 · ระดับ 9–10 ≈ B2 · ระดับ 11 ≈ B2–C1 — เป็นแค่จุดตั้งต้น (`cefrHint`) ให้ตัดสินตามความยากจริงของคำและความหมายหลักที่ผู้เรียนพบก่อน

## 7. วิธีทำงานทีละชุด (ต้องทำตามลำดับ)
1. อ่าน `work/progress.json` — `node tools/build-vocab/run.mjs progress` บอกชุดถัดไปที่ยังไม่เสร็จ (**ห้ามทำชุดที่ผ่านแล้วซ้ำ**)
2. อ่าน STYLE.md (ไฟล์นี้) + `batch-NNN.input.json`
3. เขียน `batch-NNN.output.json` ครบ 100 คำ
4. รัน `node tools/build-vocab/run.mjs validate-batch N` — แก้จนผ่าน (ผ่านแล้วสคริปต์บันทึกลง `work/progress.json` ให้เอง)
5. ถ้าเซสชันถูกตัด ครั้งหน้าเริ่มจากข้อ 1

## 8. เช็กลิสต์ก่อนส่งชุด
- [ ] ครบทุกคำของชุด ตรง rank/word
- [ ] `th[0]` เป็นความหมายที่พบบ่อยที่สุด และใช้ Wiktionary ก่อนเมื่อมีตัวเลือก (source + basedOn ครบ)
- [ ] ประโยคทุกประโยคมีคำนั้นหรือรูปผัน ≥ 4 คำ แต่งใหม่ ไม่ซ้ำ
- [ ] แท็ก/ CEFR ถูกต้องตามรายการ · family เฉพาะคำในคลัง
